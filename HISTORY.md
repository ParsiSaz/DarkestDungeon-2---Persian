# Changelog & Version History

All notable changes to the **Darkest Dungeon II Persian Localization Project** are documented here.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), adhering to [Semantic Versioning](https://semver.org/).

---

## [v1.2.0] - 2026-10-04

### Changed
- Standardized repository architecture to conform with the **ParsiSaz 2026 Localization Standard (L10N-STD-2026)**.
- Organized POT build scripts into `tools/`, source templates into `loc/templates/`, and binary assets into `game_assets/`.
- Updated signature `README.md` with installation guides and links to the [ParsiSaz Documentation Portal](https://parsisaz.github.io/parsisaz/).

---

## [v1.1.0] - 2023-10-25

### Added
- Updated POT string extraction tools and binary asset generation scripts.
- Completed translations for act bosses, quirks, combat skills, and stagecoach upgrades.

---

## [v1.0.0] - 2023-05-15

### Initial Release
- Initial Persian localization package for Darkest Dungeon II 1.0 release.
